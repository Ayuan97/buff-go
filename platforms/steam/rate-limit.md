| 信号 | 观测 |
|---|---|

| 302 | Location 指向 login：会话失效，**不是**限流信号 |
| 403 | 账号页 path（activelistings 等），非本轮主采集限流 |

## 采集策略建议（非正式策略数字）

1. 目录：`search/render` 登录。两种 429 要分开处置：健康窗内打太快是**短锁**，30s 仍 429、**60s 恢复**；桶被打空是**长锁**，静默 45min 仍 429、**60m34s 后**才恢复。长锁期间 2s 轮询实测 20×429，提早重试无用。  
2. 深度：优先 **orderbook Load + qp**；与 search 分桶；本窗未测到上限。  
3. 勿假设全站统一 QPS；按 path 分预算。  
4. 写接口未测，禁止当作采集通道。
