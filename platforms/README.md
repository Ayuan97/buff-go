# 平台接口资料

本目录保存平台采集接口文档、真实入参语义和脱敏后的响应证据。

开发调试 Cookie 只允许放在 `platforms/private/<platform>/cookie.md`。该目录必须被 Git 忽略，文件权限必须为 `0600`；接口文档不得记录 Cookie 值、账号标识、完整响应正文或 `Set-Cookie`。

## 接口记录规则

每个已确认的接口使用一个独立 Markdown 文件，并在对应平台的 `README.md` 中登记。文件名使用简洁的小写英文，例如 `sell-summary.md`、`buy-orders.md`。

每份接口文档至少记录：

1. 接口用途，以及属于求购 `bid` 还是出售 `ask`。
2. 请求地址、GET 或 POST、目标线路和登录要求。
3. Query、Path、Header 或 Body 入参及其真实含义。
4. 分页方式、游标含义、总数和结束条件。
5. 返回字段结构，以及平台商品 ID、Steam 关联字段和商品名称字段。
6. 价格字段、金额单位和人民币校验方式。
7. 订单数量与商品件数的字段口径。
8. 空数据、不支持、登录失效、解析失败的判断方式。
9. 429、403、验证码等限频信号，以及实测冷却时间。
10. 求购与出售是否共享接口类型和限频预算。
11. 最近验证日期、验证结论和仍未确认的事实。

只记录经过实际请求确认的内容。不能凭字段名称猜测语义，也不能把参考价、成交价或推荐价直接当成最高求购价或最低出售价。
