# 控制台使用说明

控制台运行在本机回环地址，面向系统所有者。它用于配置 Steam 采集资源、启停采集方向，并查看运行状态和行情结果。

## 完整操作旅程

1. 打开控制台，在资源页创建 Steam 账号，以及 `direct` 或 `proxy` 节点。
2. 人工记录节点的公网出口 IP、有效期和地域；代理节点同时选择 `static` 或 `sticky` 出口模式。
3. 将 Steam 账号绑定到允许的 `foreign` 或 `hongkong` 节点。
4. 在概览添加 Steam 游戏并开启出售方向。
5. 系统开始发现商品并持续记录最低出售价；需要求购价时再开启求购方向。
6. 在运行页查看组合当前认领和最近提交批次。
7. 在行情页筛选商品，在商品详情查看各方向结果和近 30 天变价。
8. 关闭方向后等待状态变为已停止；已经保存的行情继续保留。

出售方向负责搜索和发现商品，求购方向只扫描已经发现的商品目录。没有商品目录时，单独开启求购方向不会产生新商品。

## 页面一览

| 页面 | 主要操作与信息 | 刷新行为 |
| --- | --- | --- |
| 概览 | 添加 Steam 游戏；启停出售、求购方向；移除从未提交过页面且已停止的方向 | 每 3 秒刷新 |
| 资源 | 创建、修改或删除账号与节点；替换 Cookie；记录出口 IP 与有效期；建立账号节点绑定 | 进入页面及写入后刷新 |
| 配置 | 设置搜索排序、出售价格区间；为 Rust 设置 Steam 分类和物品类型；保存代理商与地域水位 | 进入页面及写入后刷新 |
| 运行 | 只读查看组合、当前认领和最近提交批次 | 每 2 秒刷新 |
| 行情 | 按游戏、方向、关键字、价格、分类和降价条件筛选；手动刷新或启用可选周期刷新 | 筛选条件保存在浏览器本地 |
| 商品详情 | 查看出售、求购的最近尝试、最近有效价和价格变化 | 每 10 秒刷新 |
| 规则 | 只读查看当前能力状态 | 进入页面时读取 |

## 资源配置

节点分为直连和代理：

- `direct`：本机直连，出口模式固定为 `static`。
- `proxy`：代理连接，可以使用固定出口 `static`，或在一段会话内保持出口的 `sticky`。

节点地域为 `domestic`、`foreign` 或 `hongkong`。Steam 只使用 `foreign` 和 `hongkong` 节点。节点参与采集前必须记录公网出口 IP 和有效期；有效期到达后停止派工，使用者需要重新记录出口。

账号状态含义：

- `unverified`：凭据已经录入，等待下一次成功采集验证。
- `valid`：最近一次会话验证成功。
- `invalid`：会话失效，不能领任务。

替换 Cookie 后账号回到 `unverified`。账号、节点和绑定关系有占用或引用时，删除操作会被拒绝。

地域水位表示使用者期望保留的最少可用代理数量。水位和代理商目前只保存配置，不会自动获取代理、验证出口或创建节点。

## 启停与采集条件

添加游戏时会创建一个关闭的 Steam 出售方向。首次开启尚不存在的求购方向时，系统再创建对应目标。

方向开关表达使用者期望：

- `enabled`：持续采集。
- `disabled`：停止采集。

后台状态表达实际进度：

- `starting`：已开启，正在准备执行。
- `running`：正在持续执行。
- `waiting`：兼容已有的方向级等待状态，到达复查时间后自动恢复；单个组合的网络失败不会把整个方向置为等待。
- `blocked`：资源、限频或配置条件暂不满足；带下次检查时间时自动复查，否则需要修正配置后重新启用。
- `stopping`：正在清理任务并收敛停止。
- `stopped`：已经停止。
- `error`：仅用于不能自动恢复的调度异常；单个组合的临时网络失败只回队退避，资源不足进入 `blocked`。修复异常后关闭并重新开启该方向。

关闭是异步过程。操作成功只表示系统接受了停止意图；后台清理未完成任务后收敛为已停止。已经发出的请求可以结束，但旧开关版本的结果不能写入。只有从未成功写入过页面、已经关闭且停止完成的方向可以移除。

配置页可以修改出售搜索顺序、价格区间，以及 Rust 的 Steam 分类和物品类型。修改这些条件会清理未完成任务，并从新条件起点重新搜索；已经保存的行情继续保留。求购订单簿不使用这些出售搜索条件。出售与求购方向相互独立：关闭出售方向后不再发现新商品，仍开启的求购方向继续扫描已有目录。

## 运行与行情

系统按采集方向保存最近成功提交的一个采集批次：ask 是一页搜索结果，bid 是一个商品的订单簿摘要。运行页以账号节点组合为单位：当前认领说明组合正在执行什么；最近提交批次只会出现在实际提交它的账号与出口所在行。某方向后来由其他组合提交后，先前组合不再保留该方向的旧批次。当前认领和最近提交互不替代。

行情页每张卡表示一个商品、平台和方向，显示最近尝试、最近有效价格、采集时间和降价信息。文本和价格草稿只在点击筛选或按回车后生效；已加载不超过 200 条时，周期刷新会原位刷新已加载范围，超过后暂停周期刷新，手动刷新会回到首屏。商品详情汇总同一商品各方向结果，并展示近 30 天变价。

最近尝试可以是：

- `present`：取得明确有效行情。
- `empty`：平台明确表示当前没有订单。
- `unavailable`：该商品或方向不可访问。
- `failed`：已取得商品结果，但金额或响应语义无法安全接纳。

请求、登录或网络失败时，任务自动重试，不会用失败结果批量覆盖行情。较新的尝试为空、不可用或失败时，最近有效价仍保留原采集时间，并且不会显示为本次有效结果。

## 当前能力边界

- 概览和采集执行只包含 Steam。
- BUFF、IGXE 账号与地域组合可以保存，但不会产生采集任务。
- 规则页固定显示 `detail_unavailable`，表示详情采集不可用；没有规则列表、详情任务和完整订单快照。

## 本地控制面安全

- 控制台只监听本机回环地址。
- GET 用于读取，JSON POST 用于修改。
- 服务端校验 Host、同源 Origin 和 CSRF。
- 会话与代理凭据只在创建或替换时提交，查询接口不回显原文。
- 当前 POST 若因 CSRF 过期而失败，不会自动重放；下一次操作会重新获取控制上下文。
- JavaScript 和 CSS 从同源加载；商品图片可以来自 Steam CDN。
